How this maps to the site

One identity, app and site

Same green (oklch 0.55 0.14 155), same Sora + Instrument Sans pairing, same faint-green neutrals and soft rounded cards. The app doesn't just work like the site describes — it looks like it.

The popover mirrors your marketing shot

Ventus title, CPU °C · watts, the Quiet / Balanced / Perf / Auto segmented control, per-fan cards labelled by their sensor weighting, and the pulsing "why" reason line — lifted straight from your site's demo.

Green accent, thermal semantics apart

Green is the brand and the interaction color. The die map and status use a separate warm→hot ramp so "brand" and "this is hot" never blur — always with the number, never color alone.

Both themes carry the green

Dark mode isn't an inversion — it re-steps the same green identity against deep green-black surfaces, brightening the accent so it stays lively on the dark ground.
